# RanchoLabs Instructor Attendance System

A secure internal attendance system for instructors to log in, capture a live selfie, and check in with a server timestamp.

## Planned features
- Instructor, manager, and admin roles
- Secure authentication
- Live camera selfie capture
- Server-side check-in timestamp
- Attendance dashboard
- Admin reporting
- 60-day active data retention
- PDF archive before cleanup

## Stack
- Next.js
- Supabase Auth, PostgreSQL, and Storage
- Tailwind CSS
- Vercel deployment

> Never commit `.env.local` or Supabase secrets.
